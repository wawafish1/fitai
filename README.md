# 轻盈计划

一个移动端优先的三个月减脂记录工具，按谭成义视频中的“根据身体反馈分阶段调整碳水”思路实现。

## 当前版本

- 个人资料与按体重计算的碳水、蛋白质、脂肪目标
- 手机拍照或相册上传，手动确认食物和三大营养素
- 体重、腰围、饥饿、碳水渴望、精神、训练和睡眠记录
- 每 10 或 15 天复盘，并给出碳水与蛋白质系数调整建议
- 数据和压缩后的餐食照片保存在当前浏览器设备

## 本地运行

```bash
npm ci
npm run dev
```

生产构建：

```bash
npm run build
```

## 可选的餐食视觉识别

首版在没有服务端模型时会明确提示手动填写，不会伪造识别结果。若以后接入图像识别服务，设置 `VITE_AI_MEAL_ENDPOINT`；该接口接收字段名为 `image` 的 `multipart/form-data`，并返回：

```json
{
  "label": "午餐",
  "foods": "米饭、鸡胸肉、西兰花",
  "carbs": 55,
  "protein": 40,
  "fat": 15
}
```

API 密钥只能保存在服务端，不能放入 `VITE_` 环境变量。

## 说明

本工具用于记录和整理个人反馈，不构成医疗或营养处方。有疾病、用药、饮食失调史或异常不适时，应先咨询专业人士。
